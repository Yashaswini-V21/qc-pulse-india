### rfm_segments.csv
**Generated by:** `05_rfm_segmentation.ipynb`  
**Purpose:** Customer-level RFM scores and segments  
**Records:** 3,898 unique customers

| Column | Type | Description |
|--------|------|-------------|
| `customer_id` | string | Customer identifier |
| `recency` | integer | Days since last purchase |
| `frequency` | integer | Total number of orders by customer |
| `monetary` | float | Total spending by customer (INR) |
| `recency_score` | integer | Recency score (1-5, 5=most recent) |
| `frequency_score` | integer | Frequency score (1-5, 5=most frequent) |
| `monetary_score` | integer | Monetary score (1-5, 5=highest spender) |
| `RFM_Score` | integer | Combined RFM score (sum of 3 scores) |
| `segment` | string | Customer segment (Champion/Loyal/Potential/At-Risk/Churned) |

**Segmentation Logic:**
```
RFM Score 13-15 → Champion (Best customers)
RFM Score 10-12 → Loyal (Regular customers)
RFM Score 7-9   → Potential (Growth opportunity)
RFM Score 4-6   → At-Risk (Declining engagement)
RFM Score 3-5   → Churned (Inactive/lost)
```

### price_matrix.csv
**Generated by:** `03_price_intelligence.ipynb`  
**Purpose:** Price comparison across platforms by category  
**Records:** 15-20 rows (one per category)

| Column | Type | Description |
|--------|------|-------------|
| `category` | string | Product category |
| `blinkit_median_price` | float | Median price on Blinkit (INR) |
| `zepto_median_price` | float | Median price on Zepto (INR) |
| `bigbasket_median_price` | float | Median price on BigBasket (INR) |
| `blinkit_avg_discount` | float | Average discount % on Blinkit |
| `zepto_avg_discount` | float | Average discount % on Zepto |
| `bigbasket_avg_discount` | float | Average discount % on BigBasket |
| `blinkit_gap%` | float | Blinkit price gap vs market average (%) |
| `zepto_gap%` | float | Zepto price gap vs market average (%) |
| `bigbasket_gap%` | float | BigBasket price gap vs market average (%) |
| `lowest_price_platform` | string | Platform with lowest median price |
| `highest_discount_platform` | string | Platform with highest discount % |

**Gap Calculation:**
```
Gap% = ((Platform_Median - Market_Average) / Market_Average) * 100
Negative = Below market average (cheaper)
Positive = Above market average (expensive)
```

### cohort_retention.csv
**Generated by:** `06_cohort_retention.ipynb`  
**Purpose:** Customer retention by cohort (acquisition month)  
**Records:** 24 rows (monthly cohorts from Jan 2014 - Dec 2015)  
**Columns:** 13 (Month 0-12 retention percentages)

**Structure:**
```
Index      Month_0  Month_1  Month_2  Month_3  ...  Month_12
Jan-2014   100.0    18.5     12.3     9.8     ...  5.2
Feb-2014   100.0    16.8     11.5     8.9     ...  4.8
...
Dec-2015   100.0    15.2     10.1     7.6     ...  N/A
```

**Interpretation:**
- Row = Cohort (customers acquired in that month)
- Column = Months after acquisition
- Value = % of original cohort still active
- Month_0 = 100% (all new customers)
- Month_1 = 1-month retention rate
- Month_12 = 1-year retention rate

**Key Metrics:**
```
Average Month-1 retention: 14.3%
Average Month-3 retention: 9.2%
Best cohort: Jun-2015 with 26.3% Month-1 retention
```

## 📋 Column Definitions

### Standard Columns (across datasets)

#### Price Columns
- **`price`** — Current selling price (INR, Indian Rupees)
- **`mrp`** — Maximum Retail Price (list price before discount)
- **`discount_pct`** — Discount as % of MRP: `(MRP - Price) / MRP * 100`

#### Date Columns
- **`order_date`** — Transaction date (YYYY-MM-DD format)
- **`first_order_date`** — Customer's first purchase date
- **Dates are in UTC/IST** timezone

#### ID Columns
- **`customer_id`** — Anonymized unique customer identifier (not personally identifiable)
- **`product_id`** — Unique product identifier (may vary across platforms)
- **`order_id`** — Unique transaction identifier

#### Category Columns
- **`category`** — Specific product category (e.g., "Whole Milk", "Basmati Rice")
- **`master_category`** — Broader grouping (e.g., "Dairy", "Bakery & Grains")

**Standardized Categories:**
```
Dairy
Fresh Produce
Bakery & Grains
Beverages
Meat & Snacks
Other
```

#### RFM Scoring (1-5 scale, higher is better)
- **`recency_score`** — How recently customer purchased (5 = last week, 1 = 1+ year ago)
- **`frequency_score`** — How often customer purchases (5 = weekly, 1 = once or twice)
- **`monetary_score`** — How much customer spends (5 = high spender, 1 = low spender)

## 🔍 Data Quality Notes

### Completeness
| Dataset | Null Values | Handling |
|---------|------------|----------|
| `blinkit_clean.csv` | <1% | Minimal, filled with 0 or category mean |
| `zepto_clean.csv` | <1% | Same approach |
| `bigbasket_clean.csv` | <1% | Same approach |
| `groceries_clean.csv` | <2% | Rows with NULL customer_id removed |
| `rfm_segments.csv` | 0% | Calculated, no nulls |
| `cohort_retention.csv` | ~8% | Later months have fewer cohorts (expected) |

### Validation Rules Applied
✅ **Prices:** All prices ≥ 0 (removed negative/error values)  
✅ **Discounts:** 0% ≤ discount ≤ 100%  
✅ **Dates:** All dates between 2014-2016 for transactional data  
✅ **Ratings:** 0 ≤ rating ≤ 5 (where present)  
✅ **Quantities:** All quantities > 0  

### Data Limitations
- ⚠️ **Zepto data:** May have higher percentage of discount products (newer platform aggressive pricing)
- ⚠️ **BigBasket:** Likely includes bulk/larger pack sizes (affects price comparison)
- ⚠️ **Blinkit:** Premium positioning may affect pricing analysis
- ⚠️ **Groceries data:** 2-year snapshot (2014-2015), not current

## 🔗 Data Relationships

### Entity Relationships

```
Customer (3,898 unique)
├── Orders (5,000 transactions)
│   └── Order Items (by quantity)
│       └── Products (on Blinkit/Zepto/BigBasket)
│           └── Category (standardized)
└── RFM Segment
    └── Customer Journey (first category → outcome)
```

## 🔄 Data Refresh & Maintenance

### How to Update Data

1. **Add new raw files** to `data/raw/`
2. **Update notebook paths** in `01_data_load.ipynb`
3. **Run all notebooks in order:**
   ```bash
   cd notebooks/
   jupyter nbconvert --to notebook --execute --inplace 01_data_load.ipynb
   # ... repeat for 02_cleaning through 07_sankey
   ```
4. **Verify outputs** in `data/clean/`
5. **Restart Streamlit app:** `streamlit run app.py`

### Version Control
- Raw data files (`data/raw/`) should NOT be committed to Git (use .gitignore)
- Processed files (`data/clean/`) can be committed as reference/testing data
- Notebooks should be version controlled
